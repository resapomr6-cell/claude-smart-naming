# 智能命名 Smart Naming

## 目的
杜绝 AI 偷懒生成的 `output_20261116_<随机串>.md` 这类天书文件名，让每个文件一看名就知道内容。

## 规则

### 1. 文件名主体 = 内容摘要
- 用 2~8 个字概括文件内容，作为文件名主体。
- 语言：中文内容用中文；代码/技术类用英文 kebab-case（小写 + `-`）。
- 例：`DNS泄漏排查.md`、`dns-leak-fix.md`

### 2. 禁用（绝不作为主体）
`output`、`result`、`temp`、`tmp`、`new`、`final`、`未命名`、`untitled`，以及任何随机串（hash / UUID / 时间戳乱码，如 `a1b2c3`、`f3e9`）。

### 3. 日期 / 版本（关键判断）
口诀：**这文件未来会不会有第二版？**
- 不会（一次性任务）→ 不加日期：`DNS泄漏排查.md`
- 会（论文 / 项目 / 长期日志）→ 加日期或版本：`论文综述_20261116.md`、`实验方案_v2.md`
- 跨周月的长任务 → 建专属目录（`论文_XXX/`），目录内用日期/版本组织，别靠文件名堆日期。

### 4. 分类目录
文件放进对应顶层分类目录，文件名本身保持干净：
`报告/`（正式产出）、`笔记/`（思考记录）、`工具/`（脚本配置）、`临时/`（可删草稿）、`论文/` `项目/`（长任务）。

## 重命名存量乱文件
遇到已存在的 `output_*` / `result_*` / 随机串命名文件：读取内容 → 提炼摘要 → 按本规则重命名并告知用户。

## 关联
本 skill 只负责「命名」。文件的组织、归档、清理、去重，交给 [[output-governance]] 的 `govern.py` 引擎。
